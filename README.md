# From Repeated Choices to Reusable Preference Models: Learning Across Pareto Fronts

**Authors:** Matteo Brunelli and Betania S. C. Campello

This repository contains the **Python code, experimental data, and supplementary materials** associated with the research article *From Repeated Choices to Reusable Preference Models: Learning Across Pareto Fronts*.

## About the research

This study investigates how preferences expressed through repeated choices on successive Pareto fronts can be accumulated to learn a reusable preference model.

We use UTASTAR to estimate additive value functions from preference information collected over successive decision rounds. The resulting models are evaluated on previously unseen Pareto fronts to assess their predictive performance.

The experimental framework uses multi-objective knapsack problems (MOKP) and considers linear and non-linear underlying value functions, different numbers of objectives, and alternative specifications of the estimated marginal value functions.

## Repository contents

The repository provides:

- **Python code** for generating multi-objective knapsack instances, constructing supported Pareto fronts, simulating decision-maker preferences, and implementing sequential preference learning with UTASTAR.
- **Experimental data** generated by the Monte Carlo simulations used in the article.
- **Analysis scripts and supplementary results** for evaluating predictive performance and examining the evolution of the learned preference models.

The experiments investigate how the accumulation of preference information, the number of objectives, and the flexibility of the estimated marginal value functions affect prediction on unseen Pareto fronts.

## Experimental setup

The main experiments use 300 Monte Carlo replications, 20 sequential decision rounds, and 10 additional Pareto fronts for out-of-sample evaluation. We consider two, three, and four objectives; preferred-group selection rates of 10% and 30%; and UTASTAR models with two or four characteristic points per marginal value function.

Predictive performance is assessed using the predictive weighted Kendall coefficient.
